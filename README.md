# 🌸 Teachers' Day 2026 — CSE–Data Science, Section D

A beautiful and personalized **Teachers' Day tribute website** created by the students of **CSE – Data Science, Section D, 2nd Year** to celebrate and appreciate our wonderful lecturers.

The website is designed as an elegant digital tribute where each lecturer has a dedicated card containing a personalized message, quote, and tribute experience.

---

## ✨ Features

* 🎓 **Teachers' Day 2026 themed landing page**
* 🏫 MRECW branding and logo
* 👩‍🏫 Personalized cards for all six lecturers
* 💌 Individual tribute messages
* 💬 Special quotes for each lecturer
* 🌷 Faculty photo placeholders
* ✨ Smooth animations and hover effects
* 📱 Fully responsive design
* 🎨 Elegant purple, orange, and cream visual theme
* 🖱️ Interactive tribute modal for each lecturer
* 🔗 Designed for future individual lecturer tribute links

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate into the project

```bash
cd teachers-day
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local development server provided by Vite.

## 🎨 Design

The website follows a soft and elegant visual style using:

* Cream/off-white backgrounds
* Purple typography and accents
* Orange highlights
* Rounded cards
* Soft shadows
* Subtle gradients
* Smooth hover animations
* Responsive layouts

The goal is to create a **warm, personal, and memorable experience** rather than a traditional college website.

---

## 💌 Tribute Experience

When a visitor selects a lecturer's card, an interactive tribute window opens containing:

1. Lecturer's name
2. Lecturer's role
3. Faculty photo area
4. Personalized quote
5. Personal message from the students
6. Teachers' Day greeting

Faculty photographs can be added later without changing the overall structure.
